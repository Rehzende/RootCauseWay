Features

⚙

A2A Agent Orchestration

Google A2A protocol for multi-agent coordination. Triage, evidence collection, RCA, and postmortem agents work together.

$

Mixed Model Cost Optimization

Route tasks to the right model. Use Haiku for triage, Sonnet for analysis, Opus for complex root cause reasoning.

🔒

JIT Credential Vault

Just-in-time credentials for agent access to infrastructure. Scoped, time-limited, fully audited.

📚

Skills Registry

Register and discover agent skills. Dynamic capability matching for investigation tasks.

📈

Real-time Cockpit

Live dashboard showing active investigations, agent status, evidence trails, and confidence scores.

↻

Loop Engineering

Feedback loops that improve investigation quality over time. Learn from past incidents to get faster and more accurate.
